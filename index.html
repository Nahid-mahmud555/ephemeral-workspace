How it works

02 / FLOW
01
Choose your workspace

Select a folder using the browser's native permission prompt. The timer starts after access is granted.

02
Work as usual

Scan checks direct files in the selected folder for last-modified times during this session. Scan again to refresh the list.

03
Review, then burn

Review candidates and confirm. The app attempts to delete only matching files, then reports each result in the activity log.

Privacy by design

Permission-based accessYour browser asks you to select and grant access to a folder.
Transparent reviewCandidate files are listed before deletion; this tool does not delete files silently.
Local-only workflowThis page does not upload your files to a server.
Important: deletion is not secure erasureRemoving a file entry does not guarantee data is unrecoverable. Backups, cloud sync, trash behavior, filesystem journaling, and SSD wear-leveling may retain copies. Use only on folders and files you own or are authorized to manage.
